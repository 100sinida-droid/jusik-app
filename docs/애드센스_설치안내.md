# 애드센스 · 콘텐츠 페이지 안내

## 추가된 것

### 콘텐츠 페이지 (guide/ 폴더, 14개)
- **한강**: 수온 가이드, 물놀이 안전, 공원 가이드, CCTV 가이드
- **주식**: 코스피 기초, 용어 사전, 상위 종목, 초보 실수
- **필수 법적 페이지**: 소개(about), 문의(contact), 개인정보처리방침(privacy), 이용약관(terms), 면책조항(disclaimer)
- **허브**: guide/index.html (전체 목록)

각 콘텐츠 페이지는 1,500자 이상의 독창적인 한국어 콘텐츠로 작성했습니다.

### 애드센스 코드 (모든 페이지 <head>에 삽입 완료)
- `<meta name="google-adsense-account" content="ca-pub-7938956361770773">`
- `<script async src="...adsbygoogle.js?client=ca-pub-7938956361770773">`
- 메인 index.html과 guide/ 하위 14개 페이지 전부에 들어가 있습니다.

## 배포 방법
전과 동일합니다. 이 폴더 전체를 저장소(jusik-app)에 덮어쓰고 push하면 됩니다.
- guide/ 폴더와 assets/ 폴더가 반드시 함께 올라가야 합니다.

## 애드센스 신청 전 체크리스트
- [ ] https://stockmind.kr 접속 정상 (도메인 SSL 활성화 후)
- [ ] https://stockmind.kr/guide/index.html 열림
- [ ] https://stockmind.kr/guide/privacy.html 열림 (개인정보처리방침 — 필수)
- [ ] 각 페이지 하단 푸터에 소개·문의·개인정보·약관·면책 링크 보임
- [ ] 메인 상단 "📚 정보 가이드" 버튼으로 콘텐츠 이동 가능

## 애드센스 승인 팁 (2026년 기준)
1. **도메인 SSL이 반드시 활성화**되어 https로 열려야 합니다 (현재 네임서버 반영 대기 중).
2. **개인정보처리방침·소개·문의 페이지는 필수** — 없으면 자동 거절. (이미 만들었습니다.)
3. 승인 심사는 보통 며칠~2~4주 걸립니다.
4. 신청 후에도 광고가 바로 안 뜨고 "투명 광고"로 대기하다가 정식 승인됩니다.
5. contact.html의 이메일 주소(stockmind.kr@gmail.com)를 실제 본인 이메일로 바꾸는 것을 권장합니다.

## 수정하고 싶을 때
콘텐츠 텍스트는 guide/ 폴더의 각 .html 파일에서 직접 수정하면 됩니다.
공통 디자인은 assets/site.css 에서 바꿀 수 있습니다.
