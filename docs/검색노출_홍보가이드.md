# 한강 수온 라이브 — 검색 노출 & 홍보 실행 가이드

이 사이트를 사람들이 검색으로 찾아오게 만드는 순서입니다.
효과 큰 것부터 정리했어요. 위에서부터 하나씩 하시면 됩니다.

---

## ✅ 방금 코드에 넣은 것 (배포만 하면 적용됨)

- **SEO 메타태그**: 검색 제목·설명을 "한강 수온 실시간 | 오늘 한강 온도…"로 최적화
- **Open Graph**: 카톡·페북에 링크 공유하면 예쁜 미리보기가 뜸
- **구조화 데이터(JSON-LD)**: 구글이 FAQ 리치 스니펫으로 예쁘게 표시할 수 있게
- **읽을거리 콘텐츠**: "계절별 한강 온도", "한강에서 수영해도 되나요" 등 — 검색 유입의 핵심
- **sitemap.xml / robots.txt**: 검색봇이 사이트를 잘 수집하도록

→ 이 파일들을 저장소에 올리고 배포하면 끝. 아래는 그 다음 할 일.

## 1순위 · 도메인 연결 (가장 효과 큼, 미룰수록 손해)

`.pages.dev` 서브도메인은 검색엔진이 개별 사이트로 잘 신뢰하지 않아 노출에 불리합니다.
`.kr`이나 `.com` 도메인(1~2만원/년)을 사서 붙이면 이 하나로 다른 모든 작업보다 효과가 큽니다.

1. 도메인 구입: 가비아, 후이즈, Cloudflare Registrar 등에서 원하는 주소 검색 (예: `hangang-water.kr`)
2. Cloudflare Pages → 프로젝트 → **Custom domains** → 도메인 입력 → 안내대로 DNS 연결 (5분, 무료)
3. 연결 후 `index.html`의 `canonical`·`og:url`, `robots.txt`·`sitemap.xml`의 주소를 새 도메인으로 교체
4. 검색엔진 도구에도 새 도메인으로 다시 등록

## 2순위 · 검색엔진 3곳 등록 + 사이트맵 제출

2026년 한국은 구글·네이버 경합 + AI 검색(빙/ChatGPT) 확장이라 3곳 모두 필요합니다.

### 네이버 서치어드바이저 (이미 사이트 등록함)
- **요청 → 사이트맵 제출**: `주소/sitemap.xml` 입력
- **요청 → RSS 제출**: (있으면)
- **요청 → 웹페이지 수집**: 도메인 입력 후 요청 (색인 속도 ↑)
- **검증 → robots.txt**: 수집요청 눌러 확인
- ⏳ 네이버는 수집까지 **약 14~16일**, 이후에도 전량 노출 보장은 안 됨

### 구글 서치콘솔 (search.google.com/search-console)
- 사이트 등록 → 소유권 확인 → **Sitemaps** 메뉴에 `sitemap.xml` 제출
- **URL 검사**로 색인 요청
- ⏳ 통상 1~4주

### 빙 웹마스터도구 (bing.com/webmasters)
- 등록 → 사이트맵 제출. **빙에 뜨면 ChatGPT 검색에도 노출**돼서 요즘 중요해짐
- 구글 서치콘솔에서 가져오기(import) 기능으로 5분 만에 등록 가능

## 3순위 · 나모님 채널로 초기 유입 만들기 (강점 활용)

검색 색인은 2~4주 걸리니, 그 사이 직접 유입을 만들면 검색 순위에도 도움이 됩니다.
이미 운영 중인 블로그·유튜브가 최고의 무기예요.

### 네이버 블로그 (빈터공간)
- "한강 수온 실시간 확인하는 사이트 만들어봤어요" 같은 소개글 + 링크
- 네이버는 자기 블로그 링크를 검색에 잘 태워줘서 초기 유입에 효과적
- 여름철 물놀이 시즌, 벚꽃·불꽃축제 시즌에 맞춰 발행하면 검색량이 몰림

### 유튜브 (썰포니 등)
- 영상 설명란·고정댓글에 링크
- 한강 관련 짧은 영상(수온 타임랩스, 노을 등)이 있으면 자연스럽게 연결

### 커뮤니티 (자연스럽게, 스팸 금지)
- 낚시·러닝·자전거 동호회, 지역 맘카페, 한강 관련 게시판
- "한강 수온 보기 좋은 사이트 있더라" 식으로 맥락에 맞게. 대놓고 광고면 차단당함
- 시즌 이슈(첫 물놀이, 한파로 한강 결빙 등)에 얹으면 반응 좋음

### 오픈 디렉터리 / 링크
- 관련 정보 모음글, 위키, 커뮤니티 즐겨찾기에 등록되면 검색엔진이 사이트를 더 신뢰

---

## 4순위 · 꾸준한 관리 (검색 상위 유지)

- 네이버·구글 도구에서 **색인 상태를 주 1회 점검** (누락 페이지 색인 재요청)
- 콘텐츠를 가끔 업데이트(계절별 수온 안내 갱신 등)하면 "살아있는 사이트"로 평가받아 유리
- 검색 유입 키워드를 도구에서 확인 → 사람들이 실제로 뭘 검색하는지 보고 콘텐츠 보강

---

## ⏱️ 현실적인 기대치

- 검색에 뜨기까지 **2~4주**는 걸립니다. 즉효약이 아니라 심는 작업이에요.
- "한강 수온" 같은 인기 키워드는 경쟁이 있어서, 초기엔 블로그·커뮤니티 유입이 검색보다 중요합니다.
- 도메인 연결 + 콘텐츠 + 꾸준함, 이 세 가지가 쌓이면 시즌(여름·겨울)마다 검색 유입이 늘어납니다.
